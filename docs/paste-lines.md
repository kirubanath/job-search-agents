# The five paste lines

Each job runs in its own new chat, from one paste line. Open a new chat with the Google Drive, Docs and Sheets connectors on, paste the line, and replace the parts in square brackets. The chat has no memory: the line tells it which documents to read, and the documents tell it everything else.

## Job 1 Search

Every second day, before the apply chat. Turn on Claude in Chrome first.

```
Do Job 1 Search. Read the Google Docs "Job 1 Search" and "Job 1 Search Sites" in the Drive folder "{{drive_folder}}" first. Then obey "Job 1 Search" exactly. Today is [date].
```

## Job 2 Apply

Every day, at most 5 applications. Keep the chat open for the session; start a new chat each day.

```
Do Job 2 Apply. Read the Google Docs "Job 2 Apply", "Voice and Examples" and "Facts and Answers" in the Drive folder "{{drive_folder}}" first. Then obey "Job 2 Apply" exactly. Today is [date].
```

Optional additions to the Job 2 line:

- "Snapshot first." shows the company and role snapshot and waits for "go" before it writes the rest of the pack.
- "Short letters." keeps every cover letter short.
- "Target: 30 applications." continues past the Apply rows into the Backup rows until that many are done.
- "Start at #n." starts the queue at the Apply row ranked #n.

## Job 3 Reply

When a recruiter, an agency or a referral contact writes. One message per chat.

```
Do Job 3 Reply. Read the Google Docs "Job 3 Reply", "Voice and Examples" and "Facts and Answers" in the Drive folder "{{drive_folder}}" first. Then obey "Job 3 Reply" exactly. Today is [date]. The message is from [name], [company recruiter / agency recruiter / referral contact / friend]. Here it is: [paste the message, and the job description if there is one].
```

## Job 4 Call Prep

When a call or an interview is booked. One call per chat.

```
Do Job 4 Call Prep. Read the Google Docs "Job 4 Call Prep", "Facts and Answers" and "Voice and Examples" in the Drive folder "{{drive_folder}}" first. Then obey "Job 4 Call Prep" exactly. Today is [date]. The call: [company], [role], [recruiter screen / hiring manager / past work / system design / coding / ML basics / final / offer], on [date and time], with [name if known].
```

## Job 5 Weekly Review

Once a week, on Sunday evening, or when the tracker looks untidy.

```
Do Job 5 Weekly Review. Read the Google Doc "Job 5 Weekly Review" in the Drive folder "{{drive_folder}}" first. Then obey it exactly. Today is [date].
```

## The rhythm

Search every second day; apply every day, at most 5 a day; the weekly review once a week. A skipped day loses nothing: open rows keep their status, and the next search rebuilds one clean Apply list.
